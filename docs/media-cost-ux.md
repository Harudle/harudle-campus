# 음성 사용 방식과 비용 검토

2026년 11월 9일 기준. 이 문서는 다음 기능을 결정하기 위한 제안이며, 누르고 말하기 기능은 아직 적용하지 않았습니다.

## 지금 작동하는 방식

- 사용자가 `음성 연결`을 누르면 음성 서비스에 접속하고 다른 사람의 소리를 들을 수 있습니다.
- 마이크는 처음에 꺼져 있습니다. 사용자가 직접 켤 때 브라우저의 권한이 필요합니다.
- 사람이 가까이에 없어도 `음성 나가기`를 누르기 전까지 음성 서비스에 연결됩니다.
- 회의실에 들어가면 화면을 공유할 수 있습니다. 다른 서비스로 전환하거나 연결이 갱신되면 화면을 다시 선택해야 할 수 있습니다.

## 비용이 생기는 기준

LiveKit과 Daily는 음성 서비스에 연결된 사람의 시간을 셉니다. 마이크를 꺼도 연결이 유지되면 참가자 시간이 계속 쌓입니다. 네 사람이 한 시간 연결하면 마이크를 대부분 꺼 두어도 240 참가자 분입니다. [LiveKit 한도](https://docs.livekit.io/deploy/admin/quotas-and-limits/), [Daily 요금](https://www.daily.co/pricing/video-sdk/)

Cloudflare SFU는 전달받은 데이터 양을 기준으로 합니다. 마이크를 끄면 음성 데이터는 줄일 수 있지만, 화면 공유와 다른 사람이 받는 데이터도 함께 고려해야 합니다. SFU와 TURN은 월 1,000 GB 무료량을 공유합니다. [Cloudflare 요금](https://developers.cloudflare.com/realtime/sfu/platform/pricing/)

예를 들어 화면을 초당 2 Mbps로 보내고 세 사람이 한 시간 동안 받으면, 화면 수신량은 약 2.7 GB입니다. 실제 화질과 네트워크 상태에 따라 달라지며 부가 데이터는 제외한 계산입니다. Daily에서는 한 회의에서 화면 영상을 한 번이라도 보내면 그 회의에 영상 요금 기준이 적용됩니다. [Daily 요금](https://www.daily.co/pricing/video-sdk/)

## 추천하는 사용 방식

1. 열린 공간은 기본적으로 마이크를 끄고, 사용자가 키를 누르는 동안 말하는 방식을 제공합니다. 화면에 같은 역할의 버튼도 둡니다. 키를 놓치거나 다른 창으로 이동했을 때는 마이크가 계속 켜져 있지 않게 합니다. 채팅 입력 중에는 단축키가 작동하지 않아야 합니다.
2. 회의실은 사용자가 마이크를 계속 켤지 선택할 수 있게 합니다. 오래 이야기하거나 타이핑하면서 말할 때 계속 키를 누르는 불편을 줄입니다. 현재처럼 마이크가 켜져 있는 상태를 화면에 명확히 표시합니다.
3. 참가자 시간도 줄이려면 마이크만 끄는 대신, 음성을 켠 가까운 사람이 없을 때 잠시 기다린 후 음성 서비스 연결을 종료해야 합니다. 예를 들어 30초를 기다리고, 가까운 사람이 다시 나타나면 연결을 준비할 수 있습니다. 캠퍼스의 위치 연결은 유지해야 두 사람이 서로를 발견할 수 있습니다.
4. 자동 재연결은 수 초의 지연이나 브라우저 권한 요청을 만들 수 있습니다. `가까운 사람이 오면 다시 연결할게요`처럼 현재 상태를 보여 주고, 회의실에서 화면을 공유하는 동안은 유휴 종료를 적용하지 않는 편이 좋습니다.
5. 화면 공유는 읽을 수 있는 해상도를 유지하면서 초당 화면 수를 제한하고, 보지 않는 화면은 수신을 중단하는 방식을 검토합니다. 작은 글씨가 보이는지 실제 컴퓨터에서 확인한 후 값을 정해야 합니다.

## 운영 전에 필요한 확인

- Cloudflare의 분석 값은 지연되거나 청구 기준과 다를 수 있습니다. 여유를 둔 제한은 도움이 되지만 무료량 초과를 완전히 막지는 못합니다.
- Daily의 시간 예약은 실제 사용보다 크게 계산될 수 있습니다. 서버의 예약량과 계정의 실제 청구 내역을 따로 확인해야 합니다.
- 단일 서버의 디스크 저장과 재시작 복구를 시험했습니다. 여러 EC2를 사용하는 공유 저장소 구성과 디스크 장애 복구는 아직 없습니다.
- 제공자가 바뀔 때는 모든 사람이 같은 제공자로 이동해야 합니다. 음성과 화면이 잠깐 끊길 수 있음을 미리 알려야 합니다.
- Daily 수신 권한은 서버가 설정하지만 위치는 브라우저가 보냅니다. 회의실 잠금과 사용자 인증도 없어 민감한 대화에 사용하기 전에 해결해야 합니다.
